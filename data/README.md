# XI. kerületi OSM-adatkészlet

`ujbuda_network.json.gz` a Budapest XI. kerületet leíró OpenStreetMap relationből (`221998`) készült, három egyszeri Overpass-lekérdezéssel. A fájl a módonként lecsupaszított autós és gyalogos gráf mellett a kerület OSM-ben szereplő helyszíneit és tömegközlekedési megállóit is tartalmazza.

- Licenc: Open Data Commons Open Database License 1.0 (ODbL)
- Licenc és attribúció: <https://www.openstreetmap.org/copyright>
- Újragenerálás: `python tools\download_ujbuda_osm.py`

A fájl feldolgozott adatbázis, ezért terjesztésekor az ODbL feltételeit be kell tartani. A projekt Python- és JavaScript-forráskódjának licence ettől külön kezelhető.
